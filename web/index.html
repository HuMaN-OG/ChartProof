A Supported verdict means the sentence agrees with the provided, reviewed chart—not that the source data has been independently authenticated.

What data can ChartProof check?

Chart images/PDFs: Single-series English bar charts, explicit percentages from 0 to 100, four-digit years, and one figure per upload. Confirm OCR readings before checking.

Paste values/CSV: Two columns (year, percentage), with one year and one value per row. Enter a short metric name. This route uses your reviewed input directly rather than OCR.

Supported statements: Single-year percentage checks, percentage-point changes, and relative percentage changes. Unsupported wording, headcounts and absent values yield insufficient evidence. A reviewer can manually link a calculation for other phrasing.
